# AlcottGiovanna Engineering Portfolio

Static GitHub Pages site for Luyao Pang's wastewater process engineering portfolio.

## GitHub Pages deployment

1. Create a new **public** GitHub repository named exactly: `alcottgiovanna.github.io`
2. Upload the **contents of this folder** to the repository root. Do not upload the ZIP itself as the website content.
3. Make sure `index.html`, `styles.css`, `app.js`, `.nojekyll`, and the `assets/` folder are all in the repository root.
4. In GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. After GitHub finishes deployment, the site should be available at:
   `https://alcottgiovanna.github.io/`

The site uses relative asset paths, so it is safe for GitHub Pages root hosting.
